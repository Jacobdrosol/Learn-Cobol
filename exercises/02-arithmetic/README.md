# Exercise 02: Arithmetic and Pictures

Goal: understand `PIC`, implied decimal positions, arithmetic statements, and
numeric edited display fields.

Run:

```bash
make invoice
```

Practice changes:

- Change `WS-QUANTITY`.
- Change `WS-TAX-RATE`.
- Add a discount field and subtract it before tax.
- Make a deliberate field too small and observe truncation or warning behavior.
