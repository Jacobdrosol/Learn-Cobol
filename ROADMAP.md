# 90-Day Mainframe Job-Readiness Roadmap

Month one builds the foundation in `COURSE.md`. Months two and three are where
you make the work credible enough for junior applications.

## Month 2: Depth and Public Portfolio

Technical goals:

- finish IBM Z Xplore fundamentals, advanced COBOL/JCL/VSAM/Db2 challenges when online
- complete the Open Mainframe Project COBOL course material under `third_party/`
- expand the capstone to use output files, reject files, control totals, and clear return codes
- add a JCL folder for each portfolio project
- add a `docs/design.md` to each project
- learn enough TSO/ISPF to edit, submit, and inspect jobs when you have access

Portfolio deliverables:

- `batch-payroll`: payroll report, exception report, department totals, JCL notes
- `bank-ledger`: posting report, rejects, balancing controls, restart notes
- `capstone-core-banking`: copybooks, input/output layouts, tests, modernization notes

Interview goals:

- explain every line of one COBOL program
- explain every line of one JCL member
- explain the difference between batch and online transaction processing
- explain what you would ask before changing a production COBOL program

## Month 3: Mainframe Ecosystem and Hiring

Technical goals:

- use real IBM Z access through IBM Z Xplore or another training system
- practice data sets, PDS members, USS files, job submission, SDSF output, and return codes
- complete at least one Db2 or SQL module
- complete one CICS overview module
- learn basic RACF concepts: user IDs, groups, data set permissions, least privilege
- learn Zowe Explorer or Zowe CLI enough to browse data sets and submit jobs

Portfolio deliverables:

- record a short terminal transcript of local tests
- add badges and course completions to the README only after completion
- write a "what I know / what I am still learning" section
- keep the public repo free of proprietary PDFs, credentials, and machine-specific binaries

Application strategy:

- target junior mainframe developer, COBOL developer, application support, batch support, and modernization roles
- include hybrid and onsite roles if remote-only results are thin
- look for banks, insurers, state governments, airlines, retailers, health systems, and mainframe consultancies
- search for COBOL, JCL, z/OS, CICS, Db2, IMS, VSAM, batch, mainframe, Zowe, and application support
- show tested projects first, course badges second

## Skills Employers Will Expect Eventually

Core application developer:

- COBOL, JCL, file handling, copybooks, debugging, testing
- batch scheduling concepts, return codes, abends, restartability
- Db2 SQL and embedded SQL
- VSAM concepts
- CICS concepts for online transactions
- Git and modern delivery workflow

Useful adjacent skills:

- Unix shell and z/OS UNIX System Services
- Python or Java for modernization glue
- REST APIs and z/OS Connect
- Zowe Explorer or Zowe CLI
- basic security and audit controls
- production support communication

Do not pretend to have production depth before you have it. For junior roles,
the stronger signal is disciplined learning, tested code, and clear operational
thinking.
