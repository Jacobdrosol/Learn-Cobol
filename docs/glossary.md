# Glossary

Abend: abnormal end. A failed program or job termination.

Address space: an isolated z/OS execution environment.

Batch: scheduled or submitted non-interactive work, usually record-oriented.

BMS: Basic Mapping Support, commonly used for CICS terminal maps.

CICS: Customer Information Control System, IBM transaction server for online
applications.

COBOL: Common Business-Oriented Language.

Copybook: source included in a COBOL program with `COPY`, often a shared record
layout.

Data set: z/OS-managed collection of data, roughly analogous to a file but with
mainframe-specific organization and cataloging.

Db2 for z/OS: IBM relational database for z/OS.

DD statement: JCL Data Definition statement, connecting a program resource name
to a data set, spool, inline data, or other resource.

DFSORT/SYNCSORT: sort utilities commonly used in batch jobs.

Enterprise COBOL: IBM's COBOL compiler for z/OS.

EXEC statement: JCL statement that runs a program or procedure.

File status: COBOL field that records file operation results.

GDG: generation data group, a set of related data sets with generation numbers.

GnuCOBOL: open-source COBOL compiler used locally in this repo.

IMS: IBM Information Management System, database and transaction manager.

ISPF: Interactive System Productivity Facility, menu/editor environment on TSO.

JCL: Job Control Language.

JES: Job Entry Subsystem, manages batch job input and output.

KSDS: key-sequenced VSAM data set.

Language Environment: z/OS runtime environment for languages including COBOL.

Load library: data set containing executable load modules or program objects.

PDS/PDSE: partitioned data set/library containing members.

RACF: IBM security manager for users, groups, and resource access.

Return code: numeric status from a job step or program.

SDSF: tool commonly used to inspect job output and system information.

SQLCA: SQL communication area used by embedded SQL programs.

TSO/E: Time Sharing Option/Extensions, interactive z/OS user environment.

USS: z/OS UNIX System Services.

VSAM: Virtual Storage Access Method, z/OS record-oriented access method.

Zowe: open-source framework and tooling for interacting with z/OS using modern
interfaces.

z/OSMF: z/OS Management Facility, browser/API management interface for z/OS.
