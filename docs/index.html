Course Path

Week 1

Programming and COBOL basics

Learn source layout, divisions, data fields, arithmetic, branching, tables, and small reports.

Week 2

Batch programs and files

Read input files, validate records, produce reports, compare expected output, and keep tests green.

Week 3

z/OS ecosystem

Study JCL, datasets, JES, VSAM concepts, Db2, CICS, IMS, Zowe, and operational thinking.

Week 4

Portfolio projects

Build and explain batch payroll, bank ledger, and capstone core banking examples with compile/run automation and testable outputs.

Always

Practice loop

Read a lesson, run a program, change one behavior, update expected output, rerun tests, and write what changed.

What It Covers

  1. COBOL program structure, data declarations, arithmetic, branching, loops, files, tables, sort concepts, copybooks, and subprograms.
  2. Mainframe vocabulary and workflow: z/OS, JCL, JES, datasets, job output, compilers, bind/link-edit, operations, and production support.
  3. Ecosystem awareness: VSAM, Db2, CICS, IMS, Language Environment, Zowe, IBM Z Xplore direction, and Open Mainframe Project materials.
  4. Portfolio proof: tested projects with sample inputs, expected outputs, repeatable commands, and a capstone-style banking batch process.
